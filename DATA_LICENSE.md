# Data license and source boundaries

The derived feature tensors, split tables, model predictions, and evaluation
tables created for this repository are released under the Creative Commons
Attribution 4.0 International license (CC BY 4.0), to the extent that the
author holds the relevant rights.

This repository does not redistribute original Sentinel-1 or Sentinel-2 image
products, original forest-type rasters, or original event polygons. The
underlying observations remain governed by their providers' terms. The CC BY
4.0 grant in this repository does not replace or broaden those source terms.

The numerical case arrays are extracted 64 x 64 analysis windows. They contain
six-band reflectance values, masks, model predictions, and residuals. They are
not source image products. Event labels are rasterized analytical labels and
do not reproduce the original polygon files.

Users should acknowledge the Copernicus Sentinel programme and the public
forest and event inventories described in `docs/data_provenance.md`.
